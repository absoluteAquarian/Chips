REGISTERS
====================
Up to 256 registers are available with varying types and sizes.

{00..0F}  $PTR[0-F]   - address registers
{10..2F}  $Z[00-1F]   - integer registers
{30..4F}  $FL[00-1F]  - floating-point registers
{50..5F}  $S[0-F]     - string registers
{60..9F}  $OBJ[00-3F] - object registers
{A0..AF}  $V[0-F]     - vector registers
{B0..BF}  $T[0-F]     - metadata token registers
{FA..FC}  $R[0-2]     - typeless reserved registers for pseudo-instructions
{FD}      $EX         - exception register, contains Exception object in current exception handler scope, if any
{FE}      $PS         - processor status register
{FF}      $ANS        - typeless register, contains the result of the last operation that did not specify a destination register

The processor status register is a 16-bit integer that contains the following flags:
  
    ---- ---- ---I ZNVC

$PS.C - carry flag
$PS.I - NaN flag
$PS.N - negative flag
$PS.V - overflow flag
$PS.Z - zero flag

If an integer arithmetic operation results in an overflow, the overflow flag is set.
If a floating-point arithmetic operation results in a NaN value, the NaN flag is set.
If a floating-point arithmetic operation results in infinity, the overflow flag is set.
  (If the arithmetic instruction is preceded by ".checked", an exception is thrown instead of setting the overflow flag.)

REGISTER USAGE
========================================
  $x   - standard operand, register's value is used/modified
 ($x)  - dereference operand, register is treated as a pointer to the value to be used/modified
 [$x]  - "source" operand, register is treated as a value to be used by the instruction rather than its destination, only valid for instructions which specify it

[($x)] is never used directly by the instructions in the OPCODES and PSEUDO-OPCODES lists, however it is still a valid operand.
Using [($x)] indicates that the dereferenced value of the register is a value to be used by the instruction rather than its destination.

                       |      |
ldflda $x, $y, z       | RRT  | ldtoken $R0, z
                       |      | ldflda $x, $y, $R0
                       |      |
ldsfld x               | T    | ldtoken $R0, x
                       |      | ldsfld $R0
                       |      |
ldsfld $x, y           | RT   | ldtoken $R0, y
                       |      | ldsfld $x, $R0
                       |      |
ldsflda x              | T    | ldtoken $R0, x
                       |      | ldsflda $R0
                       |      |
ldsflda $x, y          | RT   | ldtoken $R0, y
                       |      | ldsflda $x, $R0
                       |      |
ldthis                 | -    | ldarg 0    (for reference types)
                       |      | ldarga 0   (for value types)
                       |      |
ldthis $x              | R    | ldarg $x, 0    (for reference types)
                       |      | ldarga $x, 0   (for value types)

-- M --
mkarr x, $y            | TR   | ldtoken $R0, x
                       |      | mkarr $R0, $y
                       |      |
mkarr x, y             | TI   | ldtoken $R0, x
                       |      | mov $R1, y
                       |      | mkarr $R0, $R1
                       |      |
mkarr $x, y, $z        | RTR  | ldtoken $R0, y
                       |      | mkarr $x, $R0, $z
                       |      |
mkarr $x, y, z         | RTI  | ldtoken $R0, y
                       |      | mov $R1, z
                       |      | mkarr $x, $R0, $R1

-- S --
setans $x              | R    | mov $ANS, $x
                       |      |
setans x               | I    | mov $ANS, x
                       |      |
stfld $x, y            | RT   | ldtoken $R0, y
                       |      | stfld $x, $R0
                       |      |
stfld $x, y, $z        | RRT  | ldtoken $R0, y
                       |      | stfld $x, $R0, $z
                       |      |
stsfld x               | T    | ldtoken $R0, x
                       |      | stsfld $R0
                       |      |
stsfld x, $y           | RT   | ldtoken $R0, x
                       |      | stsfld $R0, $y

                       |      | vinit $R0
